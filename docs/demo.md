# 시연 순서

시연 영상(8분 안팎)을 찍을 때 따라가는 순서다. 화면은 PC 1440x900 브라우저 기준이고, 휴대폰 장면은 375x812다. 명령은 Windows PowerShell에서 저장소 폴더를 기준으로 실행한다.

장면은 두 가지다.

- **공개 지도 장면**: 공개 사이트 https://yeodh10.github.io/jeungmi-geokg/ 만 쓴다. 공개 자료만 있어서 누구나 보는 영상과 README 캡처에 써도 된다.
- **로컬 장면 (※ 표시)**: 이 컴퓨터의 로컬 서버(http://localhost:8000)다. 공개하지 않는 자료(공공시설, 도로 구간과 법정동 경계, 국가기본도, 수치지형도)와 승인 기록이 보인다. GitHub, 누구나 보는 영상, README 캡처에는 넣지 않는다. 지원서에만 붙이는 영상에도 기본으로 넣지 않는다(넣으려면 사람이 정하고 docs/decisions.md에 적는다). 로컬 기능은 말로 설명하거나 보류 자료가 화면에 없는 장면(빈 지도 위 자유 질문 칸, 기록 탭의 글자 목록 등)만 쓴다. 로컬 지도 왼쪽 아래에 '로컬 서버, 보류 자료 층' 표시가 보이면 로컬 장면이다.

## 준비

1. 공개 사이트가 최신인지 본다. 지도 아래 기준 표기가 '건물 2026년 10월, 주소 2026년 9월 기준'이면 된다.
2. ※ 로컬 장면을 찍을 때만: 시연용 제안 기록을 따로 쓴다. 실제 기록은 그대로 두고 복사본으로 승인, 반려, 정정을 한다.
   ```powershell
   Copy-Item data\processed\review\proposals.json data\processed\review\proposals.demo.json
   $env:JGK_PROPOSALS = "data\processed\review\proposals.demo.json"
   ```
3. ※ 같은 창에서 서버를 켠다. 켜면 그래프와 지도 앱 자료를 미리 만든다(`http://localhost:8000/api/status`의 `graph_loaded`가 true면 준비 끝). 이 서버는 공개 보류 자료도 그대로 읽는 로컬 화면이라 127.0.0.1 밖으로 열지 않는다.
   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn src.review.app:app --host 127.0.0.1 --port 8000
   ```
   자유 질문은 `.env`에 `ANTHROPIC_API_KEY`가 있어야 한다. 키 없이 화면만 보이려면 `.\.venv\Scripts\python.exe -m tests.serve_fake_llm`으로 띄운다(가짜 모델, 실제 호출 없음, `.env`를 읽지 않음, 승인 기록은 임시 복사본).

## 1. 문제 제기 (30초)

- README의 '국가기본도 대전환 방향과 이 프로젝트' 표로 국가기본도 대전환 4원칙(객체 원자화, 영구 식별자, 자동 갱신, AI 제안 후 사람 승인)과 이 프로젝트에서 한 것을 짝지어 보여 준다.
- "증미역 반경 1km에서 실제 공공데이터로 끝까지 돌렸다"는 점을 말한다.

## 2. 공개 지도: 5분 둘러보기 (2분)

공개 사이트 https://yeodh10.github.io/jeungmi-geokg/ 를 연다. 첫 패널의 '5분 둘러보기'를 누르면 아래 여섯 단계를 실제 화면을 움직이며 보여 준다. 언제든 닫으면 시작 전 화면으로 돌아간다.

1. 지도 전체: 반경 1km 원과 용도별 옅은 색 건물, 이름 글자.
2. 증미역 카드: 고유 주소(URI), 공식 번호(역사 건물관리번호 `1150010200106660040000001`), 위키데이터 Q59989 연결.
3. 이어진 것에서 행정동을 누른다: 소속 건물이 보라색으로 번진다. 경계선이 아니라 소속 관계로 칠한 것이라고 말한다.
4. 출처 구역과 자료 탭: '이 장소의 출처'와 '이 모양의 출처'가 따로 있고, 공개하지 않는 자료는 이름과 까닭만 적는다.
5. 묻기 '증미역 500m 안 교육연구시설': 한 문장 답, 지도 보라색 강조, 표, 접힌 SPARQL. 빌드 때 공개 범위 그래프에서 미리 실행한 답이다.
6. 기계용 원본: 같은 주소의 Turtle 파일(`index.ttl`).

## 3. 공개 지도: 찾기, 카드, 입체 보기 (1분 30초)

- '양천로 550'을 넣고 카드를 연다. 주소, 지번, '역에서 직선 N m', 행동 줄(주변 찾기, 링크 복사, 주소 복사, 기계용 원본)을 보여 준다.
- '학교' 칩을 누른다. 번호 목록과 지도 번호 표식이 같이 나오고, 지도는 움직이지 않는다.
- '올리브영'을 찾는다. 상가정보 2026년 9월 기준의 상호 카드가 열리고, 들어 있는 건물로 넘어갈 수 있다. 영업시간과 리뷰는 자료에 없다고 카드에 적혀 있다.
- '가양9단지'를 찾아 단지 카드에서 동 수와 세대수를 보여 준다.
- 고른 곳에서 '주변 찾기'를 눌러 300m 안 건수를 보여 준다. 걷는 거리가 아니라 직선 거리라는 안내를 짚는다.
- '버스'를 찾는다. 이 지도에 없는 자료라는 안내와 다음 행동이 나온다. 없는 값은 비워 두지 않고 없다고 적는다는 원칙을 말한다.
- 오른쪽 '지도 보기'에서 입체 보기를 켠다. 건축물대장 높이로 세운 LoD1 모형이고, 높이가 없으면 층수로 어림한다. 마우스로 돌리고 기울일 수 있다. 건물에 마우스를 올리면 이름과 층수가 말풍선으로 나온다.
- 휴대폰(375x812)으로 같은 주소를 연다. 아래 시트가 접힘, 절반, 전체로 움직이고, 찾기로 고른 곳이 시트에 가리지 않고 보이는 지도 가운데에 온다.

## 4. ※ 로컬 서버 지도 (1분)

- http://localhost:8000/map 을 연다. 공개 사이트와 같은 앱이고, 자료 입구만 로컬 서버로 바뀐다. 왼쪽 아래 '로컬 서버, 보류 자료 층'과 패널의 '기록' 탭이 더해진다.
- '로컬 서버, 보류 자료 층'에서 공공시설을 켠다. 23곳이 나오고, 하나를 누르면 카드가 열린다. 공개 사이트에 없는 객체라서 카드에 '장소 페이지 열기'가 없고 '기계용 원본'은 꺼져 있다.
- 도로 구간과 국가기본도 건물을 켠다. 우리 건물 위에 국가기본도 건물 외곽이 겹쳐 보인다. 값과 번호는 이 화면에서만 보이고 문서에는 적지 않는다.
- 말할 것:
  - 국가기본도 지형지물 분류(수치지도 작성 작업규칙 제9조)를 어휘에 넣었다.
  - 번호가 서로 맞지 않는 곳이 실제로 있다(GIS건물통합정보 A21과 국가기본도 UFID가 하나도 같지 않음). 그래서 모양으로 짝을 찾고 공식 번호(PNU, 주소)로 한 번 더 확인한다.
  - 건축물대장과 국가기본도의 층수가 다른 건물을 쿼리 하나로 찾는다(`src/graph/queries/13_basemap_floor_check.rq`).

## 5. ※ 실제 고시로 자동 갱신 (2분)

- 강서구청 누리집의 "도로명주소 폐지 고시(제2026-140호)"와 첨부 폐지조서를 보여 준다.
- 검토 화면 http://localhost:8000 을 연다. 목록이 고시별로 묶여 있다.
- "서울특별시 강서구 등촌로55길 11-13"을 고른다.
  - "무엇이 바뀌나": 건물과 주출입구의 상태가 사용에서 폐지로, 폐지 확인일 2026-10-28
  - 근거: 고시 번호, 폐지조서 줄, 도로명주소와 지번이 같은 건물을 가리킨다는 확인
  - SHACL 검사 통과 표시
- 고시 머리 줄의 "대기 5건 묶어 결정"을 누른다. 앞 제안을 반영한 그래프에서 다음 제안을 차례로 검사한 결과가 나온다. 검토자 이름을 넣고 "통과한 5건 승인"을 누른다(시연용 복사본).
- '지도에서 확인'을 누른다. 로컬 지도 앱이 그 건물 카드를 열고, 상태가 폐지로 바뀌어 있다.
- 기록 탭의 '승인 바로 전 값과 견주기'를 누른다. 승인 1초 전 시점의 값(상태 사용, 폐지 확인일 없음)을 그래프에서 되살려 지금 값과 나란히 보여 준다. 판마다 그래프를 복사하지 않고 바꾼 트리플 기록만으로 지난 시점을 되살린다는 점을 말한다. '검토 화면에서 보기'로 검토 화면에 돌아간다.
- 검토 화면 "승인" 탭에서 한 건을 열고 "결정 정정하기"로 대기 상태로 되돌린다(사유: 시연용 정정). 앞의 결정이 정정 이력에 그대로 남고, 그래프는 그 변경만 빼고 다시 만들어진다. 기록을 지우지 않는다는 점을 말한다.

## 6. ※ 국가기본도로 만든 제안과 검토 기준 (1분)

- 검토 화면 "승인" 탭에서 "국가기본도 주소로 주소 미연결 건물 잇기"(41건 중 39건 승인, 뒤에 전수조사로 5건을 철회해 지금 34건)를 연다. 근거에 "확인 필요"가 적힌 한 건을 고른다. 근거 세 줄: 국가기본도 건물과 겹침, 같은 주소의 점 건물까지 거리, 세 출처의 PNU 비교. 출처끼리 PNU가 달랐지만, 그 지번이 내비게이션용DB의 관련 지번에 있어 승인한 경우다.
- "반려" 탭에서 "점만 있는 건물에 국가기본도 건물 모양 붙이기"의 한 건을 연다. 예: 고층 아파트 동에 아주 작은 1층 구조물 모양이 붙는 제안. 반려 사유에 기준과 그 근거가 적혀 있다.
- 말할 것:
  - 검토 기준을 감으로 정하지 않았다. 이미 이은 1,834쌍에서 '다른 건물과 겹치는 비율', '넓이', '층수 차이'의 분포를 재서 기준을 정했다(겹침 10% 초과, 15㎡ 미만, 국가기본도 2층 이하인데 대장이 3층 이상 높음, 설명 안 되는 PNU 차이).
  - 그 기준을 규칙 코드(`src/review/basemap_proposals.py`)에 다시 넣었다. 검토 결과가 다음 자동 제안을 더 낫게 만드는 구조다. 이 결정은 사람이 맡긴 검토자 Claude가 했고, 기록의 검토자 이름에 그대로 남아 있다.
  - 그 뒤 전수조사로 규칙을 더 조였다. 승인 139건 중 13건이 규칙 밖이 되어 정정 API로 철회했다. 그중 5건은 겹친 상대가 0.08㎡짜리 자리표시라는 것을 찾아내, 규칙을 고친 뒤 다시 승인했다. 기록은 지우지 않고 정정 이력으로 쌓인다. 지금 감사(`python -m src.review.basemap_proposals --audit`)에 걸리는 건은 0건이다.
  - 같은 날 주소 미연결 건물을 세 갈래로 더 이었다: 자리표시 모양뿐인 건물 7동, 전자지도 건물 모양 7동, 범위 경계에 걸쳐 주소를 잃은 건물 34동. 앞서 승인한 국가기본도 주소 잇기 34동과 합치면 주소 미연결 건물이 628개에서 546개로 줄었다.
  - 공개 사이트에는 국가기본도, 전자지도를 근거로 한 승인을 얹지 않는다. 근거가 모두 공개 자료인 자리표시 잇기 7건만 얹는다.

## 7. AI 부분과 평가 (1분)

- 공개 장면: 묻기 탭의 미리 실행한 답(2번의 5단계)으로 질문이 GeoSPARQL(`geof:sfIntersects`) 쿼리로 바뀐 것을 보여 준다.
- ※ 로컬 장면: 묻기 탭 위 '자유 질문' 칸에 "증미역 500m 안 교육연구시설 건물을 지도에 보여줘"를 넣는다. 칸 위에 키가 있는지와 유료 호출이 생긴다는 안내가 먼저 나온다(키가 없으면 보내지 않는다). 답에는 'AI가 만든 쿼리로 찾은 답'이 붙고, 지도 보라색, 표, 만든 SPARQL이 나온다.
- 말할 것:
  - LLM은 바뀌는 내용만 뽑고, 객체를 찾아 URI를 정하는 일은 코드 규칙이 한다. 주소로 찾은 건물이 여럿이면 제안을 만들지 않는다.
  - 실제 모델로 잰 값([docs/llm-eval.md](llm-eval.md)): 자연어 질의 25문제 중 23문제 맞음(나머지 2개도 정답은 결과에 있음), 실제 강서구 고시 95건에서 근거 문장과 주소를 지어낸 것 0건.
  - 고시 변경 종류에 구역 지정, 해제, 사업 인가, 준공을 더해 분류되지 않던 변경(other)이 90%에서 2%로 줄었다. 구역에는 공통 번호가 없어서, 고시 번호를 공식 번호로 삼아 고시를 객체로 만들고 필지와 잇는다.

## 8. 표준과 마무리 (40초)

- 공개 사이트의 어휘 페이지 https://yeodh10.github.io/jeungmi-geokg/def/ 의 "바깥 표준 어휘와 잇기" 표를 보여 준다. schema.org, INSPIRE 지형지물 개념, 위키데이터, BOT와 이었고, 바깥 주소는 실제로 열리는 것만 쓴다([docs/interop.md](interop.md)).
- 공개 지도에서 센서 카드를 열고 '장소 페이지 열기'로 간다. 기온, 습도, 소음, 조도, 자외선의 1주일 꺾은선이 있다. 센서와 관측은 W3C와 OGC 공동 표준 SOSA/SSN으로, 단위는 QUDT로 적었다.
- `python -m src.pipeline` 한 줄로 원본에서 그래프, 센서, SHACL 검사, 예시 쿼리, 상호운용성 검사, 공개 사이트까지 다시 만든다.
- 전국으로 키울 때([docs/scale-design.md](scale-design.md)): 그래프를 20배로 키워 재 보니 번호로 찾기는 그대로(0.3ms), 모양으로 찾기는 비례해 느려졌다(87ms에서 4.6초). 그래서 객체 원장(모양, 공간 색인)과 지식 그래프(관계, 이력)를 나누고, 시군구 단위로 바뀐 것만 처리하도록 설계했다.
- 남은 일: 국토지리정보원의 답을 받아 국가기본도 공개 여부 정하기, 사람이 직접 승인 기록 다시 보기.
