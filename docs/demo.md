# 시연 순서

시연 영상(8분 안팎)을 찍을 때 따라가는 순서다. 화면은 1440x900 브라우저 기준이다. 명령은 Windows PowerShell에서 저장소 폴더 기준이다.

## 준비

1. 그래프를 새로 만든다 (약 7분).
   ```powershell
   .\.venv\Scripts\python.exe -m src.pipeline
   ```
2. 시연용 제안 기록을 따로 쓴다. 실제 기록은 그대로 두고 복사본으로 승인, 반려, 정정을 한다.
   ```powershell
   Copy-Item data\processed\review\proposals.json data\processed\review\proposals.demo.json
   $env:JGK_PROPOSALS = "data\processed\review\proposals.demo.json"
   ```
3. 같은 창에서 서버를 켠다. 켜면 그래프를 미리 불러 둔다(`http://localhost:8000/api/status`의 `graph_loaded`가 true면 준비 끝).
   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn src.review.app:app --port 8000
   ```
4. 이용 조건을 확인 중인 자료가 있다: 공공시설(민원행정기관 전자지도), 도로 구간과 법정동 경계(도로명주소 전자지도), 국가기본도, 수치지형도.
   영상을 누구나 볼 수 있게 올린다면 이 자료가 나오는 장면(아래 ※ 표시)은 이용 조건을 확인한 뒤에 찍는다. 지원서에만 붙이면 그대로 찍어도 된다.

## 1. 문제 제기 (30초)

- README 첫 표로 국가기본도 대전환 4원칙(객체 원자화, 영구 식별자, 자동 갱신, AI 제안 후 사람 승인)과 이 프로젝트에서 한 것을 짝지어 보여 준다.
- "증미역 반경 1km에서 실제 공공데이터 8종으로 끝까지 돌렸다"는 점을 말한다.

## 2. 객체와 영구 식별자 (1분)

- 지도 화면 http://localhost:8000/map 을 연다. 증미역이 고른 상태로 열린다.
- 왼쪽 패널에서 연결을 따라간다: 역 → 역사 건물(증미역 9호선) → 법정동 등촌동, 기초구역 07550, 주소의 도로 양천로.
- URI가 공식 번호 그대로라는 점을 말한다: 건물관리번호 `1150010200106660040000001`, 법정동코드, 도로명코드, 기초구역번호.
- 공개 URI 페이지를 연다: https://yeodh10.github.io/jeungmi-geokg/id/building/1150010200106660040000001/ . 같은 주소로 사람용 HTML과 Turtle이 있다.
- 주황색 건물(주소 미연결 628개)을 하나 누른다. 건물관리번호가 없을 때만 GIS건물통합식별번호로 URI를 만든 규칙을 보여 준다.
- ※ 레이어에서 "도로 구간"을 켜고 양천로 구간을 누른다. 이 구간에 면한 출입구 목록이 나온다(출입구 2,180개 중 2,120개가 면한 구간에 이어짐).

## 3. 국가기본도와 잇기 (1분) ※

- 레이어에서 "국가기본도 건물"을 켠다. 우리 건물(파란 면) 위에 국가기본도 건물 외곽(분홍 선)이 겹쳐 보인다.
- 찾기에 "가양빌딩"을 넣고 고른다. 연결에 "국가기본도의 같은 건물"이 있다. 눌러서 국가기본도 객체ID(`BLD01…`), 모양 겹침 0.96, PNU와 도로명주소가 같다는 확인을 보여 준다.
- 말할 것:
  - 국가기본도 지형지물 분류(수치지도 작성 작업규칙 제9조)를 어휘에 넣었다.
  - 번호가 서로 맞지 않는 곳이 실제로 있다(GIS건물통합정보 A21과 국가기본도 UFID가 하나도 같지 않음). 그래서 모양으로 짝을 찾고 공식 번호(PNU, 주소)로 한 번 더 확인한다.
  - 강서소방서 건물은 건축물대장 4층, 국가기본도 3층이다. 이런 차이를 쿼리 하나로 찾는다(`src/graph/queries/13_basemap_floor_check.rq`). 국가기본도와 이은 1,834동 중 409동, 수치지형도와 이은 1,685동 중 393동이 층수가 다르다.

## 4. 실제 고시로 자동 갱신 (2분)

- 강서구청 누리집의 "도로명주소 폐지 고시(제2026-140호)"와 첨부 폐지조서를 보여 준다.
- 검토 화면 http://localhost:8000 을 연다. 목록이 고시별로 묶여 있다.
- "서울특별시 강서구 등촌로55길 11-13"을 고른다.
  - "무엇이 바뀌나": 건물과 주출입구의 상태가 사용 → 폐지, 폐지 확인일 2026-10-28
  - 근거: 고시 번호, 폐지조서 줄, 도로명주소와 지번이 같은 건물을 가리킨다는 확인
  - SHACL 검사 통과 표시
- 고시 머리 줄의 "대기 5건 묶어 결정"을 누른다. 앞 제안을 반영한 그래프에서 다음 제안을 차례로 검사한 결과가 나온다. 검토자 이름을 넣고 "통과한 5건 승인"을 누른다.
- 지도 화면에서 "등촌로55길 11-13"을 찾는다. 빨간색(폐지)으로 바뀌었고, "반영된 변경 제안"으로 누가 언제 승인했는지 따라갈 수 있다.
- 변경 이력의 "승인 바로 전 값과 견주기"를 누른다. 승인 1초 전 시점의 값(상태 사용, 폐지 확인일 없음)을 그래프에서 되살려 지금 값과 나란히 보여 준다. 판마다 그래프를 복사하지 않고 바꾼 트리플 기록만으로 지난 시점을 되살린다는 점을 말한다.
- 검토 화면 "승인" 탭에서 한 건을 열고 "결정 정정하기"로 대기로 되돌린다(사유: 시연용 정정). 앞의 결정이 정정 이력에 그대로 남고, 그래프는 그 변경만 빼고 다시 만들어진다. 기록을 지우지 않는다는 점을 말한다.

## 5. 국가기본도로 주소 연결 제안 (40초)

- 검토 화면에서 "국가기본도 주소로 주소 미연결 건물 잇기" 묶음을 연다(41건).
- "대림아르빌아파트" 제안을 고른다. 근거 세 줄을 읽는다: 국가기본도 건물과 겹침, 같은 주소의 점 건물이 0.1m 거리, 세 출처의 PNU 비교.
- 이 건은 GIS 쪽 PNU 끝자리가 달라 "확인 필요"로 표시된다. 기계가 확신하지 못하는 것은 사람에게 넘긴다는 점을 말하고, 반려 사유 예시 "근거 부족"으로 반려하거나 그대로 둔다.
- "점만 있는 건물에 국가기본도 건물 모양 붙이기" 묶음(208건)을 연다. 지도에서 점 건물이 국가기본도 모양 안에 있고, 근거에 주소, PNU, 층수 비교가 나온다. 승인하면 그 건물의 모양이 점에서 면으로 바뀌고, 바뀌기 전 점은 시점별 판 기록으로 되살릴 수 있다.

## 6. 센서와 표준 (50초)

- 공개 지도 https://yeodh10.github.io/jeungmi-geokg/map/ 를 연다. 서버 없이 열리는 지도다. 파란 점(센서)을 하나 누르고 "URI 페이지 열기"로 간다.
- 센서 페이지에서 기온, 습도, 소음, 조도, 자외선의 1주일 꺾은선을 보여 준다. 센서와 관측은 W3C와 OGC 공동 표준 SOSA/SSN으로, 단위는 QUDT로 적었다.
- 어휘 페이지 https://yeodh10.github.io/jeungmi-geokg/def/ 의 "바깥 표준 어휘와 잇기" 표를 보여 준다. 말할 것:
  - schema.org, INSPIRE 지형지물 개념, 위키데이터, BOT와 이었고, 바깥 주소는 실제로 열리는 것만 쓴다.
  - RDFS 추론 뒤 schema.org 이름만으로 역과 주소를 찾는다. 증미역은 위키데이터 Q59989와 같은 실물로 이었고 좌표 차이는 44.8m다([docs/interop.md](interop.md)).
  - BIM은 합치지 않고 같은 건물이라는 연결만 둔다([docs/bim.md](bim.md)).

## 7. AI 부분과 평가 (1분)

- 지도 화면 "질문하기"에 "증미역 500m 안 교육연구시설 건물을 지도에 보여줘"를 넣는다(Claude API 키 필요, 10초 안팎). 22동이 지도에 보라색 테두리로 칠해지고 목록과 설명이 나온다. "실행한 SPARQL"을 펼쳐 질문이 GeoSPARQL(geof:sfIntersects)로 바뀐 것을 보여 준다.
- 말할 것:
  - LLM은 바뀌는 내용만 뽑고, 객체를 찾아 URI를 정하는 일은 코드 규칙이 한다. 주소로 찾은 건물이 여럿이면 제안을 만들지 않는다.
  - 실제 모델로 잰 값([docs/llm-eval.md](llm-eval.md)): 자연어 질의 25문제 중 23 맞음(나머지 2개도 정답은 결과에 있음), 실제 강서구 고시 95건에서 근거 문장과 주소를 지어낸 것 0건.
  - 고시 변경 종류에 구역 지정, 해제, 사업 인가, 준공을 더해 분류되지 않던 변경(other)이 90%에서 2%로 줄었다. 구역에는 공통 번호가 없어 고시 자체를 공식 번호로 객체를 만들고 필지와 잇는다.

## 8. 마무리 (40초)

- `python -m src.pipeline` 한 줄로 원본에서 그래프, 센서, SHACL 검사, 예시 쿼리, 상호운용성 검사, URI 페이지까지 다시 만든다.
- 전국으로 키울 때([docs/scale-design.md](scale-design.md)): 그래프를 20배로 키워 재 보니 번호로 찾기는 그대로(0.3ms), 모양으로 찾기는 비례해 느려졌다(87ms → 4.6초). 그래서 객체 원장(모양, 공간 색인)과 지식 그래프(관계, 이력)를 나누고 시군구 단위로 바뀐 것만 처리한다.
- 남은 일: 이용 조건 확인 뒤 공개 범위 넓히기, 주소 연결 제안 41건과 모양 붙이기 제안 208건 검토.

## 시연 뒤

복사본으로 시연했으니 실제 기록(`proposals.json`)은 그대로다. 같은 창에서 시연용 설정을 지운다.

```powershell
Remove-Item Env:JGK_PROPOSALS
Remove-Item data\processed\review\proposals.demo.json
```
