# 시연 순서

시연 영상(5분 안팎)을 찍을 때 따라가는 순서다. 화면은 1440x900 브라우저 기준이다.

## 준비

1. `python -m src.pipeline`으로 그래프를 새로 만든다 (약 2분 40초).
2. 시연용 제안 기록을 따로 쓴다. 실제 기록을 남기려면 그대로 두고, 여러 번 찍을 거라면 복사본을 쓴다.
   ```bash
   cp data/processed/review/proposals.json data/processed/review/proposals.backup.json
   ```
3. 서버를 켠다: `python -m uvicorn src.review.app:app --port 8000`
4. 공개 보류 중인 민원행정기관 자료는 화면에 나오지 않게 지도에서 "공공시설" 레이어를 끄고, 검토 화면에서는 고용센터 제안을 고르지 않는다.

## 1. 문제 제기 (30초)

- 국가기본도 대전환 4원칙(객체 원자화, 영구 식별자, 자동 갱신, AI 제안 후 사람 승인)을 한 장으로 보여 준다 (README 첫 표).
- "작은 지역에서 실제 공공데이터로 끝까지 돌려 봤다"는 점을 말한다.

## 2. 객체와 영구 식별자 (1분)

- 지도 화면 http://localhost:8000/map 을 연다. 증미역이 선택된 상태로 열린다.
- 왼쪽 패널에서 역 → 역사 건물(증미역 9호선) → 행정동(등촌제1동) → 필지로 연결을 따라간다.
- URI가 건물관리번호 `1150010200106660040000001` 그대로라는 점, 객체가 사라져도 URI는 남는다는 점을 말한다.
- 주황색 건물(주소 미연결 628개)을 하나 누른다. 건물관리번호가 없을 때만 GIS건물통합식별번호로 따로 URI를 만든 규칙을 보여 준다.

## 3. 실제 고시로 자동 갱신 (2분)

- 강서구청 누리집의 "도로명주소 폐지 고시(제2026-140호)"와 첨부 폐지조서를 보여 준다.
- 검토 화면 http://localhost:8000 을 연다. 폐지조서에서 나온 제안 5건이 대기 중이다.
- "서울특별시 강서구 등촌로55길 11-13"을 고른다.
  - "무엇이 바뀌나": 건물과 주출입구의 상태가 사용 → 폐지, 폐지 확인일 2026-10-28
  - 근거: 고시 번호, 폐지조서 1번 줄, 도로명주소와 지번이 같은 건물을 가리킨다는 확인
  - SHACL 검사 통과 표시
- 검토자 이름을 넣고 승인한다. 다음 제안으로 넘어간다.
- 지도 화면에서 그 건물을 찾는다(찾기: "등촌로55길 11-13"). 빨간색(폐지)으로 바뀌었고, "반영된 변경 제안" 연결로 누가 언제 승인했는지 따라갈 수 있다.

## 4. AI 제안의 한계를 코드로 막은 부분 (1분)

- 고시 본문(글)은 LLM이, 첨부표는 코드가 읽는다는 구분을 말한다.
- LLM은 URI를 정하지 않는다: 주소로 찾은 건물이 여럿이면 제안을 만들지 않고 보고서에만 남긴다 (`tests/test_notice.py`의 "여러 후보" 사례).
- 규칙을 어기는 제안은 승인 버튼이 꺼진다 (`tests/test_shacl.py`).
- API 키가 있으면 지도 화면 "질문하기"에 "증미역 300m 안 학교"를 넣어 SPARQL로 바뀌는 과정과 결과를 보여 준다.

## 5. 마무리 (30초)

- `python -m src.pipeline` 한 줄로 원본에서 그래프, 검사, URI 페이지까지 다시 만든다는 점.
- 남은 일: 도로명주소 전자지도(도로 구간, 행정동 경계), 실제 LLM 실행, 배포.

## 시연 뒤

승인 기록을 시연 전으로 되돌리려면:

```bash
cp data/processed/review/proposals.backup.json data/processed/review/proposals.json
```
