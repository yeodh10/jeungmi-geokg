# 데이터 출처와 이용 조건

원본 파일은 저장소에 올리지 않는다(`data/raw/`는 .gitignore). 아래 방법으로 받아 `data/raw/` 아래 지정한 폴더에 풀면 `python -m src.ingest.clip_area`로 범위를 자를 수 있다.

받은 압축 파일(건축물대장은 CSV 그대로)은 `data/raw/_archives/`에 보관한다. `python -m src.ingest.unpack`을 실행하면 아래 각 항목의 "풀 위치"로 필요한 파일만 풀린다.

"변경 금지" 조건(공공누리 3, 4유형, CC BY-ND 계열)인 데이터는 가공해서 쓰지 않는다.

  - 근거: 공공데이터포털에 국토교통부가 등록한 "국토교통부_일별GIS건물통합정보" 메타데이터 (등록 2015-12-28, 수정 2025-09-08, 2026-10-28 확인)

  - 참고: 브이월드의 다른 데이터셋 "건물통합정보_마스터"(dsId 30524)는 CC BY-NC-ND(변경 금지)다. 이름이 비슷하지만 다른 자료이고, 우리가 쓰는 것은 AL_D010(GIS건물통합정보)이다.
- 필드 이름이 A0 ~ A28로 되어 있다. 값으로 확인한 뜻:
  - A0 파일 안 일련번호 (고유하지 않다, 식별자로 쓰지 않는다)
  - A1 GIS건물통합식별번호(28자리), A2 PNU(19자리), A3 법정동코드, A4 법정동명, A5 지번

  - A13 사용승인일, A19 건축물대장 건축물ID, A22 데이터 기준일, A24 건물명, A25 동명, A26 지상층수, A27 지하층수
  - 나머지(A12, A14 ~ A18, A20, A21, A23, A28)는 브이월드 레이어 정의서로 확인한 뒤 적는다.
- 건물 상세 속성은 이 자료 안의 건축물대장 속성(A8 ~ A27)을 쓴다.
- 건물관리번호(도로명주소 쪽 번호)는 이 자료에 없다. 내비게이션용DB 건물중심점과 공간 조인해서 붙인다(아래 "자료끼리 연결").
- A1 중복: 서울 전체 695,753행 중 고유값 695,348개, 중복된 번호 405개(788행). 반경 안에서는 1건(염창동 242-40)이며, A0만 다르고 속성과 모양이 똑같은 행이 두 번 들어 있다. 처리 규칙은 docs/uri-policy.md.

- 쓰임: **단지 보강용으로만 쓴다.** 총괄표제부는 "한 대지에 건물이 2개 이상"인 경우에만 만들어지는 대지 단위 자료라서(반경 안 95건), 개별 건물 속성에는 쓰지 않고 PNU로 필지 객체에 단지 정보(대지면적, 세대수, 주건축물수 등)를 붙인다.
- PNU 만들기: 법정동코드(10) + 대지구분(대지 1, 산 2) + 주지번(4) + 부지번(4)

- 형식: SHP 레이어 39개. 파일 이름이 `N3{A면,L선,P점}_{지형지물 코드 8자리}`이고, 코드 첫 글자가 수치지도 작성 작업규칙 제9조의 대분류(A~H)다.
- 좌표계: `.prj`가 Korea_2000_Central_Belt_2010(원점 127, 38, 가산 200,000 / 600,000, 축척 1)로 EPSG:5186과 같다. 인코딩 표시(.cpg)는 EUC-KR이지만 실제 값은 UTF-8로 읽힌다.
- 유일식별자(UFID): 모든 지형지물에 34자리. 예 `1000037608075B00110000000000000001`. 6~13번째 자리가 도엽코드다. 도엽 안에서 겹치지 않는다(건물 5,326개 모두 다름).
- 코드 뜻은 값으로 확인했다: `N3A_B0010000`은 속성 '종류'가 아파트, 일반주택, 주택외건물, 무벽건물 등이라 건물, `N3L_B0020000`은 '구분'이 담이라 담장, `N3A_G0010000`은 시도와 시군구 경계(읍면동은 없다), `N3A_H0010000`은 도곽(도엽명, 도엽코드).
- 범위: 37608075는 반경 1km 원의 96.8%를 덮고, 남쪽 약 140m가 37608085에 걸친다. 두 도엽을 합치면 99.98%이고, 남은 것은 서쪽 약 9m(37608074)다. 비교는 받은 도엽의 도곽 안에서만 한다.
- 지금 쓰는 레이어: 건물(N3A_B0010000), 도곽(N3A_H0010000)
- 이용 조건: **확인 중**. 확인 전까지 국가기본도 건물 객체는 공개 페이지에서 뺀다.

## 5-2. 국토지리정보원 국가기본도 (국토정보플랫폼 '국가기본도' 내려받기)
