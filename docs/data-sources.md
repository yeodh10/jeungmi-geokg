# 데이터 출처와 이용 조건

원본 파일은 저장소에 올리지 않는다(`data/raw/`는 .gitignore). 아래 방법으로 받아 `data/raw/` 아래 지정한 폴더에 풀면 `python -m src.ingest.clip_area`로 범위를 자를 수 있다.

받은 압축 파일(건축물대장은 CSV 그대로)은 `data/raw/_archives/`에 보관한다. `python -m src.ingest.unpack`을 실행하면 아래 각 항목의 "풀 위치"로 필요한 파일만 풀린다.

"변경 금지" 조건(공공누리 3, 4유형, CC BY-ND 계열)인 데이터는 가공해서 쓰지 않는다.

## 1. GIS건물통합정보

- 제공처: 국토교통부, 브이월드 파일 다운로드
- 받은 파일: `AL_D010_11_20261009.zip` (11은 서울)
- 풀 위치: `data/raw/vworld_gis_building/`
- 형식: SHP 폴리곤, 서울 전체 695,753개, 문자 인코딩 CP949 (.cpg 없음)
- 좌표계: .prj에 `Korea_2000_Korea_Central_Belt_2010`, `AUTHORITY["EPSG","5186"]`
- 이용 조건: **이용허락범위 제한 없음**
  - 근거: 공공데이터포털에 국토교통부가 등록한 "국토교통부_일별GIS건물통합정보" 메타데이터 (등록 2015-12-28, 수정 2025-09-08, 2026-10-28 확인)
  - 링크: https://www.data.go.kr/data/15052097/fileData.do
  - 참고: 브이월드의 다른 데이터셋 "건물통합정보_마스터"(dsId 30524)는 CC BY-NC-ND(변경 금지)다. 이름이 비슷하지만 다른 자료이고, 우리가 쓰는 것은 AL_D010(GIS건물통합정보)이다.
- 필드 이름이 A0 ~ A28로 되어 있다. 값으로 확인한 뜻:
  - A0 파일 안 일련번호 (고유하지 않다, 식별자로 쓰지 않는다)
  - A1 GIS건물통합식별번호(28자리), A2 PNU(19자리), A3 법정동코드, A4 법정동명, A5 지번
  - A6, A7 대지구분(1 일반, 2 산), A8, A9 용도코드와 용도명, A10, A11 구조코드와 구조명
  - A13 사용승인일, A19 건축물대장 건축물ID, A22 데이터 기준일, A24 건물명, A25 동명, A26 지상층수, A27 지하층수
  - 나머지(A12, A14 ~ A18, A20, A21, A23, A28)는 브이월드 레이어 정의서로 확인한 뒤 적는다.
- 건물 상세 속성은 이 자료 안의 건축물대장 속성(A8 ~ A27)을 쓴다.
- 건물관리번호(도로명주소 쪽 번호)는 이 자료에 없다. 내비게이션용DB 건물중심점과 공간 조인해서 붙인다(아래 "자료끼리 연결").
- A1 중복: 서울 전체 695,753행 중 고유값 695,348개, 중복된 번호 405개(788행). 반경 안에서는 1건(염창동 242-40)이며, A0만 다르고 속성과 모양이 똑같은 행이 두 번 들어 있다. 처리 규칙은 docs/uri-policy.md.

## 2. 도로명주소 내비게이션용DB

- 제공처: 행정안전부, 주소기반산업지원서비스(business.juso.go.kr)
- 받는 방법: 도로명주소법 시행령 제46조, 시행규칙 제53조에 따라 신청서를 쓰고 이용목적 심사를 거친 뒤 받는다.
- 받은 파일: `202609_내비게이션용DB_전체분.7z` (전국 34개 파일)
- 풀 위치: `data/raw/juso_navi_db/` (서울 파일과 공통 파일만 푼다)
  - `match_build_seoul.txt` 건물 (건물관리번호, 건물중심점, 주출입구)
  - `match_jibun_seoul.txt` 지번
  - `match_rs_entrc.txt` 보조출입구 (전국 한 파일)
  - `[가이드]내비게이션용DB 활용방법.pdf` 필드 레이아웃
- 형식: `|` 구분 텍스트, CP949, 머리글 없음, 줄 끝에 `|`가 하나 더 있다
- 좌표계: 다운로드 화면은 "ITRF2000, GRS80", 레이아웃 문서는 "GRS80 UTM-K"라고 적혀 있다. 값 범위(X 약 94만, Y 약 195만)도 UTM-K와 맞아 EPSG:5179로 쓴다.
- 비공개, 공개제한 건물은 좌표가 비어 있다. 이런 행은 범위 자르기에서 빠진다.
- 이용 조건: **이용허락범위 제한 없음**
  - 근거: 공공데이터포털 "행정안전부_도로명주소 내비게이션용DB_월간" 메타데이터 (등록 2021-12-21, 수정 2025-05-14, 2026-10-28 확인)
  - 링크: https://www.data.go.kr/data/15050419/fileData.do

## 3. 서울시 건축물대장 총괄표제부

- 제공처: 서울열린데이터광장 OA-23051
- 받은 파일: `서울시 건축물대장 총괄표제부.csv`, 19,201행, CP949
- 풀 위치: `data/raw/seoul_building_register/`
- 이용 조건: 공공누리 1유형(출처표시, 상업적 이용과 변경 가능), 저작권자 서울특별시
- 좌표계: 파일에 적혀 있지 않다. X좌표, Y좌표 값을 EPSG:5179로 보고 같은 PNU의 GIS 건물과 거리를 재 보니 89건 중앙값 5.0m, 75%가 9.2m 안이라 EPSG:5179로 판단했다.
- 쓰임: **단지 보강용으로만 쓴다.** 총괄표제부는 "한 대지에 건물이 2개 이상"인 경우에만 만들어지는 대지 단위 자료라서(반경 안 95건), 개별 건물 속성에는 쓰지 않고 PNU로 필지 객체에 단지 정보(대지면적, 세대수, 주건축물수 등)를 붙인다.
- PNU 만들기: 법정동코드(10) + 대지구분(대지 1, 산 2) + 주지번(4) + 부지번(4)
- 알려진 원천 값 문제 (SHACL 검사로 찾음, 2026-10-29): PNU 1150010100102900000 필지의 대지면적이 0이다. 원천 값을 고치지 않고 그대로 두며, 검사 보고서에 1건으로 남는다.
